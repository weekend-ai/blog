# Blog

Personal blog built with Hugo and PaperMod theme.

## Setup

After cloning this repository, you need to initialize the theme submodules:

```bash
git submodule update --init --recursive
```

This will download the Hugo themes (PaperMod and hugo-bearblog-neo) into the `themes/` directory.

## Local Development

Run the development server:

```bash
hugo server
```

The site will be available at http://localhost:1313/
